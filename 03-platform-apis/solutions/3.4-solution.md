# Solution 3.4 – Crossplane troubleshooting

```bash
kubectl -n team-a describe webapp broken        # conditions: Synced / Ready + events
crossplane beta trace webapp broken -n team-a
kubectl get functions
```

| # | Error | Where you see it | Fix |
|---|-------|------------------|-----|
| 1 | `functionRef.name: function-patch-transform` – the function does not exist (correct: `function-patch-and-transform`) | XR condition `Synced=False`, event `cannot run Composition pipeline step ... function not found` | Fix the name in the Composition |
| 2 | Typo `spec.imgae` in the patch | The Deployment keeps the image `placeholder` → `ErrImagePull`. Patches from missing fields fail **silently**! | `fromFieldPath: spec.image` |
| 3 | Image `nginx:does-not-exist` | After fixes 1+2: the Deployment never becomes Available → XR `Ready=False` | `kubectl -n team-a patch webapp broken --type=merge -p '{"spec":{"image":"nginx:1.27"}}'` |

```bash
kubectl patch composition webapp-broken --type=json -p='[
  {"op":"replace","path":"/spec/pipeline/0/functionRef/name","value":"function-patch-and-transform"},
  {"op":"replace","path":"/spec/pipeline/0/input/resources/0/patches/0/fromFieldPath","value":"spec.image"}
]'
```

## Crossplane checklist

1. `kubectl get xrd` → `ESTABLISHED=True`, `OFFERED=True`?
2. `kubectl get functions` / `kubectl get providers` → `INSTALLED` and `HEALTHY`?
3. XR `describe` → conditions `Synced` (did the reconcile work?) and `Ready` (are all resources ready?)
4. `crossplane beta trace` → which composed resource is stuck?
5. Debug the composed resource itself (`kubectl describe deploy ...`).
6. Crossplane logs: `kubectl -n crossplane-system logs deploy/crossplane`.
7. RBAC: is Crossplane allowed to create the resource? (`cannot create ... forbidden` → aggregated ClusterRole)
