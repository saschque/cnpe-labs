# Lösung 3.4 – Crossplane Troubleshooting

```bash
kubectl -n team-a describe webapp broken        # Conditions: Synced / Ready + Events
crossplane beta trace webapp broken -n team-a
kubectl get functions
```

| # | Fehler | Wo sichtbar | Fix |
|---|--------|-------------|-----|
| 1 | `functionRef.name: function-patch-transform` – Function existiert nicht (richtig: `function-patch-and-transform`) | XR-Condition `Synced=False`, Event `cannot run Composition pipeline step ... function not found` | Namen in der Composition korrigieren |
| 2 | Tippfehler `spec.imgae` im Patch | Deployment behält Image `placeholder` → `ErrImagePull`. Patches auf fehlende Felder schlagen **still** fehl! | `fromFieldPath: spec.image` |
| 3 | Image `nginx:does-not-exist` | Nach Fix 1+2: Deployment wird nie Available → XR `Ready=False` | `kubectl -n team-a patch webapp broken --type=merge -p '{"spec":{"image":"nginx:1.27"}}'` |

```bash
kubectl patch composition webapp-broken --type=json -p='[
  {"op":"replace","path":"/spec/pipeline/0/functionRef/name","value":"function-patch-and-transform"},
  {"op":"replace","path":"/spec/pipeline/0/input/resources/0/patches/0/fromFieldPath","value":"spec.image"}
]'
```

## Checkliste Crossplane

1. `kubectl get xrd` → `ESTABLISHED=True`, `OFFERED=True`?
2. `kubectl get functions` / `kubectl get providers` → `INSTALLED` und `HEALTHY`?
3. XR `describe` → Conditions `Synced` (Reconcile ok?) und `Ready` (alle Ressourcen bereit?)
4. `crossplane beta trace` → welche komponierte Ressource hängt?
5. Komponierte Ressource selbst debuggen (`kubectl describe deploy ...`).
6. Crossplane-Logs: `kubectl -n crossplane-system logs deploy/crossplane`.
7. RBAC: Darf Crossplane die Ressource anlegen? (`cannot create ... forbidden` → aggregierte ClusterRole)
