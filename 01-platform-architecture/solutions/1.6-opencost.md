# Lösung 1.6 – OpenCost

```bash
# API erreichbar machen (Port 9003 = API, 9090 = UI)
kubectl -n opencost port-forward svc/opencost 9003:9003 &

# Kosten der letzten 24 h pro Namespace
curl -sG http://localhost:9003/allocation/compute \
  -d window=24h \
  -d aggregate=namespace \
  -d accumulate=true > /tmp/cost-by-namespace.json

# Teuersten Namespace ermitteln
jq -r '.data[0] | to_entries
       | map(select(.key != "__idle__"))
       | max_by(.value.totalCost) | .key' \
  /tmp/cost-by-namespace.json > /tmp/top-namespace.txt
cat /tmp/top-namespace.txt

# Bonus: nach Label team aggregieren
curl -sG http://localhost:9003/allocation/compute \
  -d window=24h -d aggregate=label:team -d accumulate=true | jq '.data[0] | keys'
```

Wichtige Parameter der `/allocation`-API:

| Parameter | Beispiele |
|-----------|-----------|
| `window` | `24h`, `7d`, `today`, `lastweek`, `2026-11-01T00:00:00Z,2026-11-02T00:00:00Z` |
| `aggregate` | `namespace`, `controller`, `pod`, `label:team`, `namespace,label:app` |
| `accumulate` | `true` = ein Gesamtwert statt Zeitreihe |
| `idle` | `false` = Idle-Kosten ausblenden |

Alternativ mit dem `kubectl-cost`-Plugin: `kubectl cost namespace --window 24h`.
