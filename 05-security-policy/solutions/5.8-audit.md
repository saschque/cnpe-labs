# Solution 5.8 – Audit trail

The log lives in kind's control-plane container:

```bash
kubectl -n demo delete deploy podinfo   # example action (or any other test deployment)

docker exec cnpe-control-plane cat /var/log/kubernetes/audit.log \
  | jq -c 'select(.verb=="delete" and .objectRef.resource=="deployments")
           | {time: .requestReceivedTimestamp, user: .user.username,
              ns: .objectRef.namespace, name: .objectRef.name, code: .responseStatus.code}'

# Changes to RoleBindings (last hour)
SINCE=$(date -u -d '1 hour ago' +%Y-%m-%dT%H:%M:%S)
docker exec cnpe-control-plane cat /var/log/kubernetes/audit.log \
  | jq -c --arg since "$SINCE" 'select(.objectRef.resource=="rolebindings"
           and (.verb|test("create|update|patch|delete"))
           and .requestReceivedTimestamp > $since)
           | {time: .requestReceivedTimestamp, verb, user: .user.username, ns: .objectRef.namespace, name: .objectRef.name}'
```

| Level | What gets logged |
|-------|------------------|
| `None` | Nothing |
| `Metadata` | Who, when, which verb, which resource – **without** a body |
| `Request` | Metadata + request body |
| `RequestResponse` | Metadata + request and response body |

**Secrets only at `Metadata`:** with `Request`/`RequestResponse`, the secret content (base64,
i.e. plain text) would end up in the audit log – the log itself would become a secret.

Other audit/compliance sources on a platform:
- Kyverno `PolicyReport`/`ClusterPolicyReport` and Gatekeeper `status.violations`
- Argo CD: history per app (`argocd app history`) + Git log = who deployed what
- SBOMs (Syft) + scan reports (Trivy) as pipeline artifacts, possibly as OCI attestations
- Kubernetes events (`kubectl get events`) are short-lived (1 h by default) – not a replacement for auditing
